# Customer Behavior Data Analytics

## Overview

This project analyzes customer purchasing behavior using a complete **Python → MySQL → SQL → Power BI** analytics workflow.
The objective is to transform raw customer transaction data into meaningful business insights around **customer demographics, purchasing behavior, discounts, subscriptions, product performance, and revenue**.

The project also includes a structured analytical report and a presentation created using **Gamma** to communicate the key findings.

## Dataset
The project uses a customer shopping behavior dataset containing information such as:

* Customer ID
* Age
* Gender
* Category
* Item Purchased
* Purchase Amount
* Review Rating
* Subscription Status
* Shipping Type
* Discount Applied
* Previous Purchases
* Frequency of Purchases
* Other customer and transaction attributes

The raw dataset was initially loaded into Python for exploration and data preparation.

## Steps Performed

### 1. Load Dataset in Python

The CSV dataset was imported into Python using Pandas.

```python
import pandas as pd

df = pd.read_csv("customer_shopping_behavior.csv")
```

Initial inspection was performed using functions such as:

```python
df.head()
df.info()
df.describe(include="all")
df.isnull().sum()
```

This helped understand the dataset structure, data types, summary statistics, and missing values.

---

### 2. Exploratory Data Analysis & Cleaning

The dataset was analyzed and prepared for further analysis.

Key preprocessing activities included:

* Identifying missing values
* Handling missing review ratings
* Imputing missing ratings using the median rating within each product category
* Renaming columns using snake_case
* Creating customer age groups
* Converting purchase frequency into numerical day intervals
* Checking consistency between discount-related fields
* Removing redundant columns

Example transformation:

```python
df['age_group'] = pd.qcut(
    df['age'],
    q=4,
    labels=['Young Adult', 'Adult', 'Middle-aged', 'Senior']
)
```

---

### 3. Load Cleaned Data into MySQL

The cleaned Pandas DataFrame was uploaded to a MySQL database using SQLAlchemy.

The processed dataset was stored in the:

```text
customer_behavior
```

database under the:

```text
customer
```

table.

This allowed SQL queries to be executed directly against the cleaned dataset.

---

### 4. SQL Analysis

SQL was used to answer business-oriented questions, including:

* Revenue generated by gender

* Average purchase amount by shipping type
* Subscription vs. non-subscription spending
* Products with the highest discount rates
* Customer segmentation based on previous purchases
* Top products within each category
* Subscription behavior of repeat buyers
* Revenue contribution by age group

## 5. Power BI Dashboard

The cleaned MySQL dataset was connected to Power BI to create an interactive business dashboard.

DAX measures were created for important KPIs, including:

```DAX
Number of Customers =
COUNT('customer_behavior customer'[customer_id])
```

```DAX
Average Purchase Amount =
AVERAGE('customer_behavior customer'[purchase_amount])
```

```DAX
Average Review Rating =
AVERAGE('customer_behavior customer'[review_rating])
```

The dashboard was designed to provide a high-level view of customer behavior and allow users to explore trends across different customer and transaction dimensions.

# How to Run

### 1. Clone the repository

```bash
git clone <repository-url>
cd <project-folder>
```

### 2. Install Python dependencies

```bash
pip install pandas sqlalchemy pymysql jupyter
```

### 3. Open Jupyter Notebook

```bash
jupyter notebook
```

Open the project notebook and execute the Python cells sequentially.

### 4. Set up MySQL

Create the database:

```sql
CREATE DATABASE customer_behavior;
```

Configure the MySQL credentials in the Python connection code.

### 5. Load the cleaned dataset

Run the SQLAlchemy/Pandas code to write the cleaned DataFrame into the MySQL `customer` table.

### 6. Run SQL analysis

Open MySQL Workbench and execute the analytical SQL queries against:

```text
customer_behavior.customer
```

### 7. Open Power BI

Connect Power BI Desktop to the MySQL database and load the `customer` table.

Refresh the dataset if required and open/build the dashboard.
